# NAN 2026 사전 과제 제출 체크리스트

마감: **2026년 8월 10일 23:00 (KST)**

이 문서는 최종 제출 직전 누락을 막기 위한 작업표입니다. `[ ]` 항목은 링크 발급, PDF 변환 또는 외부 업로드가 끝난 뒤 반드시 확인합니다.

## 제출물 1 — 플레이 가능한 빌드 및 전체 소스 코드

- [ ] GitHub 저장소를 생성하고 전체 소스를 push했다.
- [ ] 커밋 기록을 유지했다.
- [ ] 저장소 공개 범위를 `Public`으로 설정했다.
- [ ] `npm ci && npm run build`가 새 환경에서 성공한다.
- [ ] GitHub Pages에서 링크 클릭만으로 게임이 열린다.
- [ ] 모바일과 데스크톱 최신 브라우저에서 핵심 흐름을 확인했다.
- [ ] 유료 라이선스나 별도 설치 없이 플레이할 수 있다.
- [ ] 저장소, 커밋 기록, 배포 번들에 API 키가 없다.
- [ ] `.env.local`, 로그, 로컬 비밀 파일이 Git에 포함되지 않았다.
- [ ] GitHub Pages 주소를 아래에 기록했다.
- [ ] GitHub 저장소 주소를 아래에 기록했다.

```text
웹 플레이: [GitHub Pages URL 입력]
전체 소스: [GitHub 저장소 URL 입력]
```

비공개 저장소를 선택하는 경우에만 심사 계정 `dl_gameai_reviewer@nhn.com`을 초대하고 접근 여부를 다시 확인합니다.

- [ ] 새로고침 후 진행 상태가 유지된다.

## 제출물 2 — 실제 플레이 동영상

이 저장소 작업 범위에서는 영상 제작·업로드를 제외했지만, **NAN 2026 최종 제출에는 영상 링크가 필수**입니다. 제출 전 외부 작업으로 반드시 완료해야 합니다.

- [ ] 실제 게임 화면을 30~60초로 녹화했다.
- [ ] AI 합성 영상이나 타인 영상을 사용하지 않았다.
- [ ] 시작 → 대화 → 기억 → DNA/진화 → 퀘스트 생성·완료가 영상에 보인다.
- [ ] 사용자 메시지나 브라우저 화면에 API 키 등 비밀정보가 노출되지 않는다.
- [ ] YouTube 공개 또는 일부 공개로 업로드했다.
- [ ] 로그아웃 또는 시크릿 창에서도 링크가 재생된다.

```text
플레이 영상: [YouTube URL 입력]
영상 길이: [00:00 입력]
```

## 보안 확인

- [ ] 코드 전체에서 키 형태 문자열과 `GEMINI_API_KEY=` 실제 값을 검색했다.
- [ ] `.env.local`이 Git 추적 대상이 아닌지 확인했다.
- [ ] 브라우저 번들에 Gemini 키가 포함되지 않았음을 확인했다.
- [ ] 키는 Cloudflare Worker secret 또는 서버 환경 변수에만 저장했다.
- [ ] `VITE_*` 환경 변수에는 비밀 값을 넣지 않았다.
- [ ] 노출된 적이 있는 키는 폐기하고 새 키로 교체했다.
- [ ] GitHub Pages에는 Worker URL만 연결했다.
- [ ] Worker CORS의 허용 Origin을 최종 GitHub Pages 주소로 제한했다.
